# Правила проекта TutorFlow — планировщик занятий репетитора

## 1. Язык

- Общайся с пользователем только на русском.
- Интерфейс, подписи, ошибки, пустые состояния и уведомления — по-русски.
- Технические имена файлов, функций и полей данных — на английском.
- Даты в интерфейсе: `24.10.2026`, дни недели — `Пн … Вс`, деньги — `1 500 ₽`.

## 2. Назначение и главный пользователь

- Один пользователь — репетитор, оказывающий образовательные услуги ученикам.
- Приложение локальное, для одного человека за одним компьютером.
- Ученики приложением не пользуются: вход, роли, личный кабинет ученика не нужны.
- Главная задача — видеть всё расписание целиком и быстро его менять.

## 3. Границы проекта

Входит:

- расписание занятий с просмотром всей недели и месяца целиком;
- перенос занятий по сетке (drag & drop) и через форму;
- справочник учеников: имя, предмет, контакт, ставка;
- заметки к занятию;
- повторяющиеся занятия (серии);
- статус занятия и отметка об оплате;
- сводка недели: число занятий и сумма к оплате;
- настройка графика работы;
- резервная копия JSON.

Не входит:

- сервер, облако, синхронизация между устройствами;
- авторизация, роли, доступ учеников;
- онлайн-оплата и интеграция с платёжными системами;
- рассылки, SMS, push-уведомления, внешние API и CDN;
- видеозвонки, файлы, проверка домашних заданий.

## 4. Технологии

- Только HTML, CSS и современный JavaScript (ES-модули), без фреймворков.
- Без npm-зависимостей, сборщиков, CDN, внешних шрифтов и внешних API.
- Запуск — через локальный HTTP-сервер: `node serve.js` (порт 5173).
- Все данные — в IndexedDB. `localStorage` только для мелких настроек интерфейса.
- Запрещено подменять IndexedDB массивом в памяти или `localStorage`.

## 5. Структура файлов

- `app/index.html` — семантическая разметка и каркас экранов.
- `app/styles.css` — токены, компоненты, состояния, адаптивность.
- `app/db.js` — открытие IndexedDB, схема, миграции, операции с хранилищами.
- `app/recurrence.js` — даты и правила повтора, чистые функции без DOM.
- `app/recurrence.test.js` — тесты правил повтора (`node --test`).
- `app/calendar.js` — сетки недели и месяца, drag & drop, геометрия слотов.
- `app/ui.js` — DOM-хелперы, модальные окна, уведомления, поля формы.
- `app/app.js` — состояние, рендеринг, формы, сценарии.
- `serve.js` — статический сервер без зависимостей.
- `docs/` — бриф, план, чек-лист приёмки.
- Новые файлы — только при реальной необходимости.

## 6. Схема IndexedDB

- Имя базы: `tutorflow-db`, версия схемы: `1`.
- `students` — ключ `id`; индексы `archived`, `subject`.
- `lessons` — ключ `id`; индексы `date`, `studentId`, `seriesId`, `status`,
  `slot` (`date|startTime`), уникальный `occurrenceKey` (`seriesId|occurrenceDate`).
- `series` — ключ `id`; индексы `studentId`, `active`.
- `notes` — ключ `id`; уникальный индекс `lessonId`, индексы `studentId`, `updatedAt`.
- `settings` — ключ `key`.
- `activity` — ключ `id`; индекс `at`.
- Миграции — пошагово по карте версий, прошлые шаги не переписывать.
- Операции, меняющие несколько записей, выполнять одной транзакцией.

## 7. Модели данных

`student`: `id`, `name`, `subject`, `contact`, `rate` (₽ за 60 минут),
`color`, `comment`, `archived`, `createdAt`, `updatedAt`.

`lesson`: `id`, `studentId`, `subject`, `date` (`YYYY-MM-DD`), `startTime` (`HH:MM`),
`duration` (мин, кратно 15), `status` (`planned` / `done` / `cancelled` / `noShow`),
`price` (₽), `paid`, `seriesId`, `occurrenceDate`, `occurrenceKey`, `detached`,
`createdAt`, `updatedAt`.

`series`: `id`, `studentId`, `subject`, `weekdays` (`1..7`), `startTime`, `duration`,
`intervalWeeks`, `startDate`, `endDate`, `status`, `exceptions` (массив дат),
`createdAt`, `updatedAt`.

`note`: `id`, `lessonId`, `studentId`, `text`, `createdAt`, `updatedAt`.

`settings`: `key` → `value` (`workHours`, `defaults`, `view`).

`activity`: `id`, `type`, `message`, `at`.

## 8. Бизнес-правила

- **Ученик обязателен.** Занятие без `studentId` не создаётся ни через форму,
  ни через API хранилища: `createLesson` бросает `ValidationError`.
- Дата и время хранятся строками (`YYYY-MM-DD`, `HH:MM`), без UTC-объектов.
- Занятие одного ученика не может пересекаться с другим его занятием — блокировать.
- Пересечение с занятием другого ученика — предупреждение с подтверждением.
- `duration` — от 15 до 240 минут, шаг 15.
- `price` = `rate × duration / 60`, округление до 10 ₽; можно изменить вручную.
- Изменение ставки ученика не переписывает прошлые занятия.
- Серия создаётся сразу целиком на весь период, лимит 400 занятий.
- Перенос занятия серии: `detached = true` + дата попадает в `series.exceptions`.
- Удаление занятия серии: дата попадает в `series.exceptions`.
- Правка «всё будущее» пересоздаёт только будущие `planned` и неотвязанные занятия.
- Прошедшие, `done`, `cancelled` и `detached` занятия при пересборке не удаляются.
- Опасные действия (удаление, импорт копии, очистка) — только с подтверждением.
- Перенос и удаление можно отменить в уведомлении (8 секунд, в рамках сеанса).

## 9. Обязательные сценарии

- Просмотр недели: 7 дней, все занятия видны сразу, текущее время отмечено.
- Просмотр месяца: обзор загруженности, переход к неделе.
- Список занятий месяца: фильтры по статусу, оплате и ученику, поиск.
- Создание занятия кликом по пустому слоту и кнопкой «Новое занятие».
- Редактирование, перенос, отмена, удаление, отметки «проведено» и «оплачено».
- Серия: еженедельно / через неделю / каждые N недель, по выбранным дням, до даты.
- Справочник учеников: создание, редактирование, архив, история и суммы.
- Заметка к занятию и общий список заметок с поиском.
- Сводка: занятия и суммы за неделю и месяц, неоплаченное.
- График работы: начало, конец, шаг сетки, рабочие дни, длительность и ставка по умолчанию.
- Экспорт и импорт JSON с проверкой структуры и подтверждением замены.
- Демо-данные одной кнопкой.

## 10. Визуальные правила

- Светлая тёплая тема, крупная сетка расписания, спокойные акценты.
- Основной акцент — индиго, успех — мята, предупреждение — янтарь, ошибка — коралл.
- Занятия окрашены по предмету; отменённые — приглушённые и зачёркнутые.
- Интерфейс аккуратен на ширине 1440, 1024, 768 и 390 пикселей.
- На ширине меньше 768 пикселей drag отключается, неделя прокручивается, по умолчанию список.
- У интерактивных элементов есть hover, focus-visible, disabled и active.
- Учитывать `prefers-reduced-motion`. Эмодзи не использовать как единственные иконки.

## 11. Качество

- Перед сдачей этапа: `node --check` для каждого JS-файла.
- `node --test` для `app/recurrence.test.js` — все тесты проходят.
- Проверять сохранение данных после перезагрузки страницы.
- Проверять пустые состояния и работу на пустой базе.
- Ручные проверки фиксировать в отчёте по этапу.
