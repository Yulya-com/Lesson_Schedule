# TutorFlow — планировщик занятий репетитора

Локальное веб-приложение для одного репетитора: всё расписание недели видно сразу,
занятия переносятся мышью, у учеников хранятся предмет, контакт и ставка, к каждому
занятию можно оставить заметку.

Работает без сервера и интернета. Данные хранятся в браузере в IndexedDB.

Репозиторий: <https://github.com/Yulya-com/Lesson_Schedule>

## Быстрый старт

**Самый простой способ:** двойной щелчок по файлу **`Запустить TutorFlow.bat`**
в папке проекта. Откроется чёрное окно и браузер с приложением.

Окно закрывать нельзя — пока оно открыто, приложение работает.
Чтобы остановить — закройте окно или нажмите Ctrl+C.

**Через терминал:**

```powershell
cd "Итоговый проект"
node serve.js
```

Откройте <http://localhost:5173/app/>. При первом запуске нажмите «Загрузить пример»,
чтобы посмотреть приложение в работе, или создайте первого ученика.

Альтернатива без Node.js:

```powershell
python -m http.server 5173
```

Затем откройте <http://localhost:5173/app/index.html>.

Важно: открывать `app/index.html` двойным щелчком (через `file://`) нельзя —
браузер заблокирует ES-модули и IndexedDB. Нужен именно локальный HTTP-сервер.

## Возможности

| Раздел | Что умеет |
|---|---|
| Расписание · Неделя | Сетка 7 дней, все занятия сразу, линия текущего времени, переключение недель кнопками «‹ Пред. неделя» / «След. неделя ›» и «Сегодня», перенос и растягивание мышью на любой ширине окна, создание кликом по слоту |
| Расписание · Месяц | Обзор загруженности за месяц, перетаскивание занятий на другой день, переход к неделе |
| Расписание · Список | Занятия месяца по датам, поиск и фильтры по статусу и оплате |
| Ученики | Имя и фамилия отдельными полями, предмет, контакт, ставка, карточка с историей и суммами, архив |
| Заметки | Все заметки к занятиям, поиск по тексту и ученику, автосохранение |
| Сводка | Часы, проведённые занятия, суммы к оплате и оплачено, долг по ученикам |
| Настройки | График работы, значения по умолчанию, демо-данные, экспорт и импорт JSON |

Демонстрационные данные помечены флагом `demo`. Кнопка «Удалить демо-данные»
в настройках убирает только их — ваши ученики, занятия и заметки остаются.
Кнопка «Загрузить пример» предупреждает, если в базе уже есть ваши записи.

В расписании блок занятия показывает фамилию и имя: фамилия в первой строке,
имя во второй. Ученики сортируются по фамилии, поиск работает по обоим полям.

Перенести занятие можно двумя способами: перетащить блок мышью (в видах
«Неделя» и «Месяц») или открыть занятие, указать «Новую дату» и «Новое время»
и нажать «Перенести». Оба способа проверяют наложения и позволяют вернуть
занятие на прежнее место.

Демонстрационные данные: 6 вымышленных учеников, 60 занятий на пять недель
(из них 10 — серия «Пн и Чт, 18:00»), 4 заметки, одна отмена и одна неявка.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `N` | Новое занятие |
| `T` | Перейти к сегодняшнему дню |
| `1` / `2` / `3` | Неделя / Месяц / Список |
| `Esc` | Закрыть окно |
| `Alt` + `←` / `→` | Сдвинуть выбранное занятие на день (в сетке недели) |
| `Alt` + `↑` / `↓` | Сдвинуть выбранное занятие на 15 минут (в сетке недели) |

## Проверки

```powershell
node --check app\app.js; Get-ChildItem app\*.js, serve.js | ForEach-Object { node --check $_.FullName }
npm test          # или: node --test
```

`npm test` запускает 76 тестов: модели и правила повтора, целостность данных,
резервную копию, автоматическое копирование и сервер целиком (доступность `app/`,
закрытость остальных файлов, обходы путей, заголовки безопасности, ответ на битый URL).

## Публичная демонстрация

Приложение для показа: **https://yulya-com.github.io/Lesson_Schedule/**

Публикуется из ветки `gh-pages`, в ней лежит только содержимое `app/`
(без документации, тестов и серверных файлов). Ветка `main` — исходники.

Данные на публичном сайте **не связаны** с локальными: это другой адрес,
поэтому база там своя и пустая. Для занятий с учениками используйте
локальный запуск.

## Данные и приватность

- Всё хранится локально в браузере, ничего не отправляется в сеть.
- Демо-данные вымышленные.
- Резервная копия — `Настройки → Экспорт JSON`. Импорт заменяет все данные
  и требует подтверждения.

### Автоматическая копия в папку

`Настройки → Автоматическая копия → Выбрать папку`. Папка выбирается один раз,
дальше приложение само записывает туда `tutorflow-копия-<дата>.json` при каждом
изменении данных (одна копия в сутки, перезаписывается). Файл остаётся на диске,
даже если очистить данные браузера.

- Работает в Chrome, Edge и Яндекс.Браузере (Chromium). В Firefox и Safari
  кнопка не показывается — там только ручной экспорт.
- Браузер может заново спросить доступ к папке после перезапуска: тогда в
  настройках появляется кнопка «Возобновить доступ».
- Выключение копирования не удаляет уже записанные файлы.

### Где хранятся данные

Данные привязаны к паре «браузер + адрес». `localhost:5173` в Яндекс.Браузере
и тот же адрес в другом браузере — это два разных хранилища. Открывайте
приложение всегда одним способом: двойной щелчок по `Запустить TutorFlow.bat`
(открывает в браузере по умолчанию).

Не удаляйте «файлы cookie и данные сайтов» для `localhost` и не работайте в
режиме инкогнито — это стирает базу без возможности восстановления.
