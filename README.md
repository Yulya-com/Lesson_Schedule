# TutorFlow — планировщик занятий репетитора

Локальное веб-приложение для одного репетитора: всё расписание недели видно сразу,
занятия переносятся мышью, у учеников хранятся предмет, контакт и ставка, к каждому
занятию можно оставить заметку.

Работает без сервера и интернета. Данные хранятся в браузере в IndexedDB.

Репозиторий: <https://github.com/Yulya-com/Lesson_Schedule>

## Быстрый старт

```powershell
cd "Итоговый проект"
node serve.js
```

Откройте <http://localhost:5173/app/>. При первом запуске нажмите «Загрузить пример»,
чтобы посмотреть приложение в работе, или создайте первого ученика.

Альтернатива без Node.js:

```powershell
python -m http.server 5173
```

Затем откройте <http://localhost:5173/app/index.html>.

Важно: открывать `app/index.html` двойным щелчком (через `file://`) нельзя —
браузер заблокирует ES-модули и IndexedDB. Нужен именно локальный HTTP-сервер.

## Возможности

| Раздел | Что умеет |
|---|---|
| Расписание · Неделя | Сетка 7 дней, все занятия сразу, линия текущего времени, перенос и растягивание мышью, создание кликом по слоту |
| Расписание · Месяц | Обзор загруженности за месяц, переход к нужной неделе |
| Расписание · Список | Занятия месяца по датам, поиск и фильтры по статусу и оплате |
| Ученики | Имя и фамилия отдельными полями, предмет, контакт, ставка, карточка с историей и суммами, архив |
| Заметки | Все заметки к занятиям, поиск по тексту и ученику, автосохранение |
| Сводка | Часы, проведённые занятия, суммы к оплате и оплачено, долг по ученикам |
| Настройки | График работы, значения по умолчанию, демо-данные, экспорт и импорт JSON |

В расписании блок занятия показывает фамилию и имя: фамилия в первой строке,
имя во второй. Ученики сортируются по фамилии, поиск работает по обоим полям.

Демонстрационные данные: 6 вымышленных учеников, 60 занятий на пять недель
(из них 10 — серия «Пн и Чт, 18:00»), 4 заметки, одна отмена и одна неявка.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `N` | Новое занятие |
| `T` | Перейти к сегодняшнему дню |
| `1` / `2` / `3` | Неделя / Месяц / Список |
| `Esc` | Закрыть окно |
| `Alt` + `←` / `→` | Сдвинуть выбранное занятие на день (в сетке недели) |
| `Alt` + `↑` / `↓` | Сдвинуть выбранное занятие на 15 минут (в сетке недели) |

```powershell
node --test app/db.test.js app/recurrence.test.js
```

## Данные и приватность

- Всё хранится локально в браузере, ничего не отправляется в сеть.
- Демо-данные вымышленные.
- Резервная копия — `Настройки → Экспорт JSON`. Импорт заменяет все данные
  и требует подтверждения.
