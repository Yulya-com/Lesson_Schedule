# TutorFlow — критерии готовности

Проверка перед сдачей проекта. Каждый пункт — наблюдаемое поведение,
а не «код написан».

Пометки: `[x]` — проверено при сдаче, `[ ]` — проверить вручную мышью
или через выбор файла (автоматизация этого недоступна).

## Обязательные

1. **Невозможно создать урок без указания ученика.** Кнопка сохранения
   заблокирована, попытка сохранить без ученика даёт понятную ошибку у поля,
   запись в базу не создаётся.
2. Невозможно создать урок без даты и времени.
3. Все занятия недели видны сразу, без дополнительных фильтров и прокрутки вниз.
4. В шапке недели видны число занятий и сумма к оплате; значения совпадают
   с ручным пересчётом по занятиям недели.
5. Занятие переносится мышью на другой день и время, изменение сохраняется
   после перезагрузки страницы.
6. Перенос и удаление можно отменить в течение 8 секунд.
7. Пересечение с занятием того же ученика блокируется, с другим учеником —
   требует подтверждения.
8. Ученик создаётся с именем, предметом, контактом и ставкой; карточка
   показывает историю занятий и суммы.
9. Заметка к занятию сохраняется после перезагрузки и находится поиском.
10. Серия создаёт все занятия сразу и не воскрешает перенесённые и удалённые.
11. График работы настраивается и применяется без перезагрузки страницы.
12. Экспорт JSON создаёт файл, импорт проверяет структуру и требует
    подтверждения замены.
13. Пустая база показывает подсказку «Загрузить пример» и «Добавить ученика».
14. Данные не пропадают после перезагрузки страницы.
15. Интерфейс не ломается на ширине 1440, 1024, 768 и 390 пикселей.

## Сценарии для ручной проверки

### Занятие

- [x] «Новое занятие» → кнопка «Создать» неактивна, пока не выбраны ученик,
      дата и время.
- [x] Выбор ученика подставляет предмет и считает стоимость от ставки
      (Анна, 60 мин → 2 200 ₽).
- [x] Изменение длительности пересчитывает стоимость (90 мин → 3 300 ₽).
- [x] Ручная правка стоимости не затирается при смене длительности
      (3 000 ₽ остались после перехода на 120 мин).
- [x] Занятие сохраняется и появляется в сетке на своём месте.
- [x] Повторное открытие показывает те же значения.
- [x] Попытка сохранить без ученика даёт ошибку у поля и не создаёт запись.

### Перенос

- [x] Блок перетаскивается на другой день, время привязано к шагу сетки
      (25.10 12:00 → 19.10 14:00).
- [ ] Нижняя граница растягивает длительность мышью — проверить вручную.
- [x] Перенос на занятие того же ученика блокируется с сообщением
      «У ученика уже есть занятие…».
- [x] Перенос на занятие другого ученика спрашивает подтверждение
      («Наложение занятий»).
- [x] «Отменить» в уведомлении возвращает занятие на прежнее место.
- [x] После перезагрузки занятие остаётся на новом месте.
- [x] `Alt` + стрелки сдвигают занятие (09:00 → 09:15).

### Серия

- [x] «Пн, Ср, 10:00, до 31.12» создаёт все ожидаемые занятия (18).
- [x] Правка одного занятия не меняет остальные.
- [x] Перенос одного занятия серии не возвращает его на старое место
      после перезагрузки: занятие становится отвязанным, дата попадает
      в исключения серии.
- [x] Удалённое занятие серии не появляется снова.
- [x] «Всё будущее» меняет время у будущих занятий и не трогает отвязанные
      и прошедшие.
- [x] Серия больше 400 занятий предупреждает и создаёт первые 400
      (791 → 400).

### Ученики

- [x] Ученик создаётся, редактируется, уходит в архив.
- [x] В архиве история занятий сохраняется (10 занятий у Анны).
- [x] Суммы в карточке совпадают с занятиями ученика.
- [x] Ставка меняется, прошлые занятия не пересчитываются.

### Заметки

- [x] Заметка сохраняется вместе с занятием.
- [x] Правка в разделе «Заметки» сохраняется автоматически.
- [x] Поиск находит по тексту и по имени ученика.

### Сводка и данные

- [x] Показатели недели совпадают с занятиями недели.
- [x] Отменённые занятия не входят в показатели.
- [x] Сводка месяца сходится с базой: 46 занятий, 68 800 ₽ оплачено,
      25 000 ₽ долг.
- [x] Экспорт создаёт JSON со всеми разделами.
- [x] Валидация копии отклоняет пустой файл, чужое приложение,
      более новую версию и файл без списков.
- [ ] Импорт повреждённого JSON через выбор файла — проверить вручную.
- [x] Импорт корректного файла заменяет данные только после подтверждения
      (очистка → импорт: 6 учеников, 79 занятий, 4 заметки).

## Технические проверки

- [x] `node --check` для каждого файла в `app/` — без ошибок.
- [x] `node --test app/recurrence.test.js` — 18 из 18 тестов проходят.
- [x] Консоль браузера без ошибок и предупреждений на всех экранах.
- [x] Нет обращений к внешней сети: только локальные файлы.
- [x] Данные хранятся в IndexedDB, а не в массиве и не в `localStorage`.
- [x] Настройки графика применяются и сохраняются после перезагрузки.
- [x] `showWeekends = false` скрывает выходные, но день с занятиями
      остаётся в сетке.

## Доступность

- [x] У полей формы есть подписи (`label for`), у групп — `role` и `aria-label`.
- [x] Ошибки объявляются (`role="alert"`).
- [x] Фокус видим (`:focus-visible`) и возвращается после закрытия окна.
- [x] `prefers-reduced-motion` отключает анимации.
- [x] `Esc` закрывает окно, `Tab` не выходит за пределы модального окна.
- [ ] Полный проход по интерфейсу только с клавиатуры — проверить вручную.
